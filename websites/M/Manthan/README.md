# Manthan

Rich Presence for **Manthan**, an independent digital news platform covering India, Assam, and global stories.

## Features

- Homepage detection
- Latest news detection
- Feed support
- Article detection
- Dynamic article titles
- Reading timer
- Rich Presence buttons

## Supported Pages

- /
- /latest
- /feed
- /feed/\*
- /article/\*
- /about
